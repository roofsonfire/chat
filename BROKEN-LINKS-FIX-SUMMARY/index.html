    Best Practices Established¶

    1. Relative Paths:
    2. From docs/subdir/, use ../file.md to reach docs/file.md
    3. From docs/, use file.md or ./file.md

    4. Never use docs/file.md from within docs/ directory

    5. Directory Links:

    6. Always explicitly reference README.md: dir/README.md

    7. Don't rely on automatic index resolution: dir/

    8. Code Examples:

    9. Use generic placeholders: # or README.md
    10. Avoid specific file examples that don't exist

    13. Update archived docs when moving files
